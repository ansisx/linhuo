# 林火平台 · 一键电脑版 0.3

此文件优先于目录内旧版说明。旧版平台没有被覆盖。本版不再需要机载电脑。

## 三步使用

1. 解压整个目录，不要单独移动启动文件。双击“一键启动平台.cmd”，浏览器会自动打开平台，不需要打开 public/index.html。旧版正在运行时，先在旧版点击“停止接收”或“退出平台”；旧版终端也可按 Ctrl+C。不要随意结束所有 node.exe。
2. 电脑、遥控器连接同一 WiFi。遥控器启动已有的 G12 视频桥与航线同步 APK，确保相机源能播放并开启视频转发。电脑在“连接遥控器视频”填写遥控器当前 IP 和 APK 显示的视频密码，点击“保存并连接视频”。默认桥接端口8554，不是相机内部的554端口。
3. 首页“巡检机·标注后视频”显示电脑GPU处理的画面。切换到“灭火机”可独立设置第二路原画预览。高级设置默认使用 D:/anaconda/python.exe 和随包模型，路径不同才需要修改。

数据路径：相机 → 现有图传 → 遥控器视频桥 → 局域网 → 本电脑GPU → 平台视频区。
同WiFi不等于相机自动可达：必须先启动桥接；访客WiFi或热点设备隔离可能阻断两台设备互访。

## 后续操作

- 再次双击启动会复用当前新版服务，不重复启动。关闭浏览器不会停止后台服务；点击“退出平台”才会释放端口。断开某路视频会取消该路下次自动连接。
- 设置自动保存，视频密码使用Windows账户DPAPI加密。使用同一Windows账户运行，不要把 data 目录上传到仓库。若密码保护失败，将明确报错，不会明文保存；需在正常登录的Windows桌面账户重试。
- 遥测仍在QGC单独设置转发到电脑当前IP，巡检机默认UDP14550，灭火机14560；可通过网页顶部“遥测接口（高级）”修改。连接视频不会自动修改QGC。
- 航线自动同步保留，展开“航线自动同步”做首次设置；之后QGC保存同一个 active.plan 即自动同步。手工导入也保留。
- 通用模型识别人、车等普通目标，不是火源识别；检测记录不会创建火点或下发投放指令。未接视频时不显示模拟画面。
- 最大预览目标30FPS、JPEG最大宽度960、无音频。实际帧率取决于相机、WiFi、解码和GPU，不承诺实机30FPS。此视频不用于飞行操纵。

## 检查与限制

已验证HTTP服务、重复启动复用、停止服务、自动化功能测试与网页渲染。DPAPI测试沙箱无用户加密配置，真实账户加密往返和遥控器实时视频仍待实机验证。
普通测试：node --test test/*.test.mjs。真实Windows账户可设置 TEST_WINDOWS_DPAPI=1 后运行以验证加密。
启动故障查看 data/server-error.log；仅停止本平台，不能结束不明进程。
运行环境为已有Node.js 20+、Python及OpenCV/numpy；随包DirectML运行库供Python3.12使用。其他Python版本需匹配运行库。
