# 双机森林消防平台 · 本地联调版

本版本可以实际接收双机 MAVLink 遥测、显示缩放地图与规划路线、登记和核验火点、保存人工任务交接记录、嵌入视频播放页面。没有内置 AI 模型、媒体转码服务、飞行或舵机控制接口。不要把演示画面作为真实火情。

## 启动和停止

需要 Node.js 20 或更新且受支持的版本。不需要 npm 安装。

Windows：在本文件夹的上一级目录打开 PowerShell，运行 `./启动.ps1`。如执行策略阻止，仅对此次运行使用 `powershell -ExecutionPolicy Bypass -File ./启动.ps1`。

Ubuntu：进入平台目录后执行 `node server.mjs`。

浏览器打开 http://127.0.0.1:8790 。`/?demo=1` 是明确标注的纯前端演示，不写入真实数据。正常首页不会产生模拟遥测。

运行窗口 Ctrl+C、页面“停止接收”或 `./停止.ps1` 可停止本服务并释放 UDP 端口。关闭浏览器不会关闭后台服务。不要终止全部 node.exe；原版 UDP14550 接收器如还运行，应先关闭其对应服务。新平台会提示端口占用并重试，不会抢占端口。

## 两架飞机的 QGC 设置

保持原有飞控数传连接。在各遥控器 QGC 的 MAVLink forwarding 中配置：

| 遥控器 | 转发目的地址示例 | 对应角色 |
|---|---|---|
| 巡检机 | 电脑当前局域网 IPv4:14550 | patrol |
| 灭火机 | 电脑当前局域网 IPv4:14560 | suppression |

例如电脑仍为192.168.5.25，则分别填写192.168.5.25:14550和192.168.5.25:14560；不要照抄过期IP。修改后按 QGC 提示重启。电脑和遥控器需网络可达，同一个无客户端隔离的热点可用于测试。飞控系统编号在“接入设置”填写，默认1；两个独立接收端口允许两机均为1。单端口出现同编号多个来源时平台拒绝自动选择。

10秒未更新的遥测字段置空；GPS无有效定位时不会凭空显示位置。UDP收包数不代表每种消息均支持。当前解析 HEARTBEAT、SYS_STATUS、GPS_RAW_INT、ATTITUDE、GLOBAL_POSITION_INT、VFR_HUD、BATTERY_STATUS；不验证 MAVLink 签名，不可把 CRC 当作身份认证。仅在可信局域网或受保护隧道内使用 UDP 接收。

## 地图、航线与视频

- 默认 Esri 卫星，可切普通地图、天地图影像。支持滚轮缩放、拖动和显示全部。影像清晰度取决于当地拍摄数据；放大不能创造细节。
- 天地图浏览器端 Key 保存在浏览器本地。申请白名单填写纯IP/域名（如127.0.0.1），不是 `http://127.0.0.1:8790`。以控制台当前校验规则为准；正式上线配置实际域名限制，不提交Key到源代码。
- 地图和 Leaflet 目前使用互联网资源；离线部署需要本地化合法瓦片和静态库。
- `.plan` 上传仅用于显示，最大900KB客户端限制。支持普通 SimpleItem 地理坐标点，不支持 ComplexItem 自动展开。非坐标任务项不绘制并提示；虚线只是连接展示，不是飞控完整执行轨迹。不向飞机上传任务，也不自动同步 QGC 未上传草稿。
- “接入设置”的视频 URL 必须是可嵌入的 HTTP/HTTPS **播放网页**，例如 MediaMTX 的 `http://媒体服务器:8889/patrol-annotated`。不要填 RTSP、WHEP API 或裸 `.m3u8`。来源需允许 iframe；HTTPS 平台不能嵌入被浏览器拦截的 HTTP 混合内容。
- 这里只嵌入播放器，不保证流在线。必须另行部署和联调媒体服务、编解码、ICE/TURN、防火墙和视频权限。

## 机载火点上报

默认仅回环监听，外部 NUC 不能访问。需要局域网联调时设置 HOST=0.0.0.0，并配置至少24字符随机 VIEW_TOKEN 和 INGEST_TOKEN（两个不同密钥）。网页点击“访问密钥”输入 VIEW_TOKEN。正式部署必须使用 HTTPS、设备身份、限流与防火墙；当前共享密钥不是多用户权限系统。

PowerShell 示例（将占位值替换为随机密钥，勿使用示例文字）：

```powershell
$env:HOST='0.0.0.0'
$env:VIEW_TOKEN='替换为至少24字符的随机访问密钥'
$env:INGEST_TOKEN='替换为不同的至少24字符随机设备密钥'
node server.mjs
```

环境变量：PORT默认8790、PATROL_UDP_PORT默认14550、SUPPRESSION_UDP_PORT默认14560、DATA_DIR默认本目录data。数据保存在data/state.json；备份该目录。事件和任务各限2000条，审计保留最近1000条；目前无归档UI、账户审计或数据库并发能力。用于联调，不可直接作为生产集群。

`POST /api/ingest/fire`，Content-Type为application/json，Authorization为`Bearer <INGEST_TOKEN>`：

```json
{
  "eventKey": "patrol01-session123-track17",
  "drone": "patrol",
  "label": "疑似森林火源",
  "confidence": 0.87,
  "detectedAt": 1791800000000,
  "bbox": [0.2, 0.3, 0.1, 0.15],
  "note": "可见光和热成像联合候选；待人工核验",
  "position": {
    "lat": 30.27,
    "lng": 119.72,
    "crs": "WGS84",
    "method": "经标定姿态与测距计算，待人工核验",
    "uncertaintyM": 35
  }
}
```

以上是格式示例，不是真实火点。detectedAt使用真实UTC Unix毫秒；可省略。无可信地面坐标时完全省略position，绝不填无人机自身位置。bbox为归一化左上角x、y、宽、高。eventKey在同一事件重试时保持不变，重复提交返回原事件，不产生新任务；不同飞行会话必须带唯一前缀。目前去重不合并后续位置更新，需要在核验阶段补充。

响应201表示接收并存储；200且duplicate=true表示重复；401为鉴权失败；400为格式或容量错误。上报端应采用有限指数退避、持久化待发队列和事件有效期，不无限阻塞视频线程。

## 本地管理接口

GET `/api/state`：双机遥测、配置、事件、任务、审计。

POST接口需`X-Platform-Action: write`，设置VIEW_TOKEN后同时需`X-View-Token`。浏览器同源访问，无跨域通配许可。

| 路径 | 内容 |
|---|---|
| /api/events | 人工事件，格式同上报，但eventKey可省略 |
| /api/events/review | id, action(confirm/dismiss), note；确认需positionVerified:true。可带position补充经人工核验的坐标 |
| /api/tasks | eventId, note；只允许已确认且有核验坐标的火点 |
| /api/tasks/update | id, status, note；operator_reported需slots:[1..4] |
| /api/plans | drone, name, plan（解析后的完整JSON对象） |
| /api/settings | drone, systemId, videoUrl |
| /api/stop | 停止接收服务 |

GET `/api/task/<id>` 导出人工交接JSON，不是PX4可执行任务。状态顺序draft → handed_over → operator_reported → verified；也可取消。verified只代表人工填报的事后复核，不代表传感器检测。所有任务transport固定NOT_CONNECTED，不存在解锁、飞往目标或释放接口。

## 验证

在平台目录运行 `node --test test/platform.test.mjs`。测试使用独立端口18890/18550/18560和系统临时目录，不改正式数据；测试端口需空闲。真实接入还需要地面无桨验证、视频长时运行、断链重连、位置对照、带宽和功耗测试，不能用软件测试代替。
